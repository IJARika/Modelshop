# Modelshop

Initially intended for just extracting 'dmx' (Data Model eXchange) files from reSource models, specifically Titanfall 2, it has massively grown in scope and features.

Currently the tool supports:
- extracting mesh data
- extracting animation data
- extracting vphysics data
- building an extensive qc

In the following model versions:
- 52 (Titanfall)
- 53 (Titanfall 2)

For these formats:
- QC
- DMX
- SMD
- RMAX

Additional model versions are planned in the future (currently valve source version 49 is partially supported through Titanfall's legacy parsing), as well as potentially more export formats. Not all data is parsed from newer reSource models, but the current working goal is to remedy that, targetting Titanfall 2.
